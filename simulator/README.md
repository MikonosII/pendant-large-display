# SmartPendant Large Screen Lab

Browser preview for the large-screen SmartPendant fork.

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123).

Switch between 3.5″ / 4″ / **5″ Advance (default)** / **7″ Advance** profiles. Both CrowPanel sizes share the 480×800 portrait chrome; pick the glass that fits your machine.

# SmartPendant Large Screen Lab

Browser preview for the large-screen SmartPendant fork.

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123).

Switch between 3.5″ / 4″ / **7″ 480×800 portrait** profiles to compare chrome metrics that match `Application/ScreenConfig.h` in the firmware.
